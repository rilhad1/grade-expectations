# Довідники й користувачі

- Для кого: деканат (модератор). Маршрут `/admin/directory`, код `features/directory`, API `directory`, `users`.

## Призначення

Підтримувати довідники (дисципліни, аудиторії, дзвінки) і облікові записи (запрошення викладачів, ролі).

## Що робить зараз

- Вкладки: дисципліни, аудиторії, дзвінки (`BellTime`), користувачі.
- Запрошення за паролем, що показується один раз (ADR-009); Google-вхід вмикається змінними.

## Правила й інваріанти

- Користувачі створюються лише за запрошенням.
- Пароль входу й спроби: ліміт IP + пошта (ADR-012).
- Довідники org-scoped; назва аудиторії унікальна в коледжі.

## Напрямок

Один екран довідників за макетом, самообслуговування для викладачів (зміна пароля).

## Покращення (за пріоритетом)

1. Тимчасовий пароль не зникає при кліку поза діалогом (повторно його не отримати).
2. Видалення аудиторії/дисципліни з перевіркою використання; частково-унікальний індекс аудиторій.
3. Довідники одним екраном за макетами (беклог).
4. Безпека (CSP, глобальний ліміт тощо): відкладено власником, §5 беклогу.

## Відкриті питання

- OQ-3: повний перелік прав модератора; чи може редагувати оцінки (зараз заборонено).
- OQ-10: 2FA для модераторів.
