# Пара (екран заняття)

- Для кого: викладач, під час пари. Маршрут `/lessons/$lessonId`, код `features/lesson`, API `journal/service.ts`.

## Призначення

Швидко (ціль: група з 25 студентів ≤ 15 с) відмітити присутність, поставити оцінки й тему, завершити пару, у тому числі без інтернету.

## Що робить зараз

- Макет C (зроблено): рядок студента = прізвище, явний перемикач «Був | н», оцінки чіпами, поле швидкої оцінки (цифри, Enter або вихід із поля зберігає; тип за видом заняття; поза шкалою не зберігається) і «+» (шторка з типом оцінки та клавіатурою). Тап по прізвищу відкриває меню відміток (нп, з). Для шкали «зараховано» поля немає, лише кнопка «+ оцінка».
- Тема з тематичного плану, «Завершити» (HELD), скасування завершення протягом 10 хв.
- Потік: вкладки груп і «Завершити для всіх груп».
- Усі дії йдуть операціями через outbox (офлайн, LWW по клітинці).

## Правила й інваріанти

- `lesson.finish` ставить HELD і заповнює «присутній» для невідмічених; офлайн-відмітки не перебиваються (`editedAt` epoch) **[підтверджено]**.
- Проведене заняття змінюється лише в режимі «Змінити відмітки й оцінки»; скасування завершення 10 хв (OQ-21/30).
- Відвідуваність: `PRESENT`/`ABSENT` основні, `EXCUSED` (нп) і `LATE` (з) через меню прізвища. Усе пишеться з `editedAt` пристрою (майбутній час обрізається).
- Аудит у `ChangeLog` у тій самій транзакції (ADR-016).

## Напрямок

Макет C (великий список з перемикачем «Був/н» і полем оцінки для одного пальця) **[підтверджено, зроблено]**; далі: перевірка на реальному телефоні й жести.

## Покращення (за пріоритетом)

1. Перевірка макета C на реальному телефоні та в темній/світлій темах (знято лише в темній на 375 px); за потреби ущільнити рядок (зараз ≈84 px, видно ~6 студентів).
2. Кнопка «Скасувати завершення» вимикається після 10 хв.
3. Швидкі жести: «усі присутні», «позначити відсутніх по одному».
4. Пряма прив'язка теми до заняття в API плану тем.
