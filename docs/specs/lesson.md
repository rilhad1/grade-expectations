# Пара (екран заняття)

- Для кого: викладач, під час пари. Маршрут `/lessons/$lessonId`, код `features/lesson`, API `journal/service.ts`.

## Призначення

Швидко (ціль: група з 25 студентів ≤ 15 с) відмітити присутність, поставити оцінки й тему, завершити пару, у тому числі без інтернету.

## Що робить зараз

- Список студентів, відмітка «присутній/н», оцінки заняття (`GradeSheet`), тема з тематичного плану, «Завершити» (HELD) і скасування завершення протягом 10 хв.
- Потік: вкладки груп і «Завершити для всіх груп».
- Усі дії йдуть операціями через outbox (офлайн, LWW по клітинці).

## Правила й інваріанти

- `lesson.finish` ставить HELD і заповнює «присутній» для невідмічених; офлайн-відмітки не перебиваються (`editedAt` epoch) **[підтверджено]**.
- Проведене заняття змінюється лише в режимі «Змінити відмітки й оцінки»; скасування завершення 10 хв (OQ-21/30).
- Відвідуваність лише `PRESENT`/`ABSENT`. Усе пишеться з `editedAt` пристрою (майбутній час обрізається).
- Аудит у `ChangeLog` у тій самій транзакції (ADR-016).

## Напрямок

Макет C: великий список студентів з перемикачем «Був/н» і полем оцінки, придатний для одного пальця **[підтверджено, ще не зроблено]**.

## Покращення (за пріоритетом)

1. Макет C (мобільний-first) і візуальна перевірка на телефоні.
2. Кнопка «Скасувати завершення» вимикається після 10 хв.
3. Швидкі жести: «усі присутні», «позначити відсутніх по одному».
4. Пряма прив'язка теми до заняття в API плану тем.
