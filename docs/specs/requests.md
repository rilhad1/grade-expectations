# Запити на перенесення (деканат)

- Для кого: деканат. Маршрут `/admin/requests`, `/admin/moderation`, код `features/requests`, API `requests`, `availability.ts`.

## Призначення

Розглянути запити викладачів на перенесення або заміну пари: показати вільні слоти і погодити/відхилити з коментарем.

## Що робить зараз

- Чипи статусів із лічильниками, три колонки: список, запит («Зараз → Бажано»), вільні слоти.
- «Погодити» переносить або скасовує заняття; відмова вимагає коментар.
- Вільні слоти враховують курс групи (ADR-030).

## Правила й інваріанти

- Розклад змінює лише деканат **[підтверджено]** (OQ-4).
- Перенесення не перебиває проведені заняття й не створює конфліктів викладача/аудиторії/групи.
- Усе org-scoped.

## Напрямок

Один клік «погодити найкращий слот»; запити видно викладачеві в реальному часі.

## Покращення (за пріоритетом)

1. Список показує найновіші запити (зараз 10 найстаріших), обмежений відповідно до ролі.
2. Потік: запит на всю пару, а не лише одну групу.
3. `MOVED` оригінал не блокує повернення на старий час.
4. Коментарі й історія запиту.
5. Екран «Модерування» поки порожній: визначити призначення (коментарі до змін? перевірка даних?) [питання].
