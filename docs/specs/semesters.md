# Семестри й майстер нового семестру

- Для кого: деканат. Маршрут `/admin/semesters`, код `features/semesters`, API `semesters`, `attestations` (періоди).

## Призначення

Завести навчальний рік і семестр, задати періоди по курсах (канікули, рубіжна, директорська, сесія), перевести групи на наступний курс і перенести навантаження.

## Що робить зараз

- Майстер: рік → семестр → періоди по курсах → переведення груп (`promoteGroups`) → копіювання навантажень (`cloneSemester`, з `streamId`).
- Семестр 2026/27: 1.09–23.12.2026.

## Правила й інваріанти

- Період має необов'язковий курс (0/null = усі) і впливає на `teachingDays(semester, course)` (ADR-030).
- Переведення ідемпотентне за іменем групи когорти; випускні групи не переводяться (потрібна перевірка у майстрі).
- Дати періодів не вигадуються (OQ-18): беруться від користувача.

## Напрямок

Новий семестр за 5 хвилин: майже все копіюється з попереднього, деканат лише правит дати.

## Покращення (за пріоритетом)

1. Двокрокове створення (рік→семестр) без відкату: зробити атомарним або повторюваним.
2. Майстер не позначає випускні групи для переведення за замовчуванням.
3. Крок 4 «Шаблон розкладу» (спільно з конструктором).
4. Редагування періоду має оновлювати дати `Attestation` (див. attestations.md).

## Відкриті питання

- Фактичні дати канікул, рубіжної, ДКР і сесії (OQ-18).
