# Розклад викладача і запити на перенесення

- Для кого: викладач. Маршрут `/schedule`, код `features/teacher-schedule`, API `lessons`, `requests`.

## Призначення

Показати власний розклад (день/тиждень) з урахуванням парності тижнів і дати викладачеві спосіб попросити перенесення або заміну, не змінюючи розклад самостійно.

## Що робить зараз

- Тижневий і денний вигляд, потоки однією карткою.
- Запит на перенесення/заміну (`RescheduleRequest`) з бажаним часом; статус видно викладачеві.

## Правила й інваріанти

- Викладач **не змінює розклад сам**, лише через запит **[підтверджено]** (OQ-4).
- Дати в зоні Europe/Kyiv, парність тижнів із `weekParity` (31.08 = TOP).
- Заняття з відмітками й проведені не переносяться.

## Напрямок

Менше ручної координації з деканатом: запит → погодження → розклад оновлюється сам.

## Покращення (за пріоритетом)

1. Перевірити візуально на мобільному (не переглянуто) **[беклог]**.
2. Місячний і семестровий вигляд, ICS-підписка (є) як основний «зовнішній» календар.
3. Запит для потоку лекцій працює лише для однієї групи (`availability.ts` вважає братів потоку зайнятими): виправити.
4. `MOVED`-оригінал блокує повернення на старий час: виправити.
5. Стан запиту в реальному часі (зараз потрібне оновлення).
