# Навантаження

- Для кого: деканат. Маршрут `/admin/loads`, код `features/loads`, API `loads`.

## Призначення

Закріпити за викладачем дисципліну, групу (підгрупу), вид занять, години й форму контролю у семестрі: це основа розкладу, журналу й вичитки.

## Що робить зараз

- Створення/редагування навантажень (окремий запис на вид занять, OQ-8), `gradingRules`, `controlForm`.
- Об'єднання лекцій у потік (`POST /loads/stream`) і вихід із нього.

## Правила й інваріанти

- Споріднені навантаження (той самий семестр/дисципліна/група/підгрупа) утворюють один журнал, основне: PRACTICE→LAB→SEMINAR→CONTROL→LECTURE.
- Зміна шкали блокується, якщо є оцінки (`assertScaleUnlocked`, у т. ч. `PATCH /loads/:id`).
- Потік: один семестр, дисципліна, викладач, різні групи, без підгруп.
- Видалення — м'яке; `deleteLoad` не повинне ламати історію.

## Напрямок

Навантаження створюються пакетно й копіюються між семестрами; зміна викладача у потоці/парі не губить журнал.

## Покращення (за пріоритетом)

1. Пакетне створення навантажень з таблиці/шаблону.
2. `deleteLoad`/`deleteDiscipline`/`deleteRoom` з перевіркою використання.
3. Планові години по дисципліні й групі: від користувача.
4. Відображення потоку в колонці годин (щоб не плутати зі «зайвими» годинами).

## Відкриті питання

- OQ-8: один запис з розбивкою Л/ПР/ЛР чи окремі записи (зараз окремі).
