# Сьогодні

- Для кого: викладач (головний екран). Маршрут `/`, код `features/today`, API `journal/today.ts`.

## Призначення

Відповісти на питання «що в мене зараз і що лишилось зробити» за кілька секунд: які пари сьогодні, які вже проведені, де не відмічено, що горить (атестація, ризикові студенти).

## Що робить зараз

- Пари на сьогодні (потокові лекції однією карткою «КІт-31, 32, 33, 34»), статус, лічильник відміток, перехід на екран пари.
- Банер найближчої атестації, зведення по навантаженнях, підказки ризику.
- Працює офлайн (копія занять ±14 днів у Dexie), опитує сервер раз на 60 с.

## Правила й інваріанти

- Читає «сьогодні» з однієї точки (`FAKE_TODAY` лише для e2e, ADR-015). Дати рядками `YYYY-MM-DD`.
- Ризик і пропозиції беруться з тих самих функцій, що й журнал (`@ge/domain`), а не рахуються окремо **[підтверджено]**: розбіжності з журналом недопустимі.
- Не показує чужих занять; заміна викладача: права за `Lesson.teacherId` (OQ-22).

## Напрямок

Екран «одна дія»: від нього до відмітки пари мінімум дотиків, особливо з телефона **[підтверджено]**.

## Покращення (за пріоритетом)

Зроблено (2026-10-28): `today.ts` без N+1 (одне запитання про навантаження пар, розміри груп і ризик рахуються паралельно, групування за студентом); опитування `today` у фоновій вкладці TanStack Query і так призупиняє.

1. Ризик рахується по кожному навантаженню окремо (розбіжність із журналом, де вид занять фільтр): звести до спільної функції з `getGradebook`.
2. Кеш відповіді `/today` на ~30 с на користувача (пара запитів поспіль від різних екранів).
3. Швидкий вхід у «Пару» з пропущених (непроведених) занять попередніх днів.
4. [пропозиція] Підсумок дня: що проведено/не проведено.
