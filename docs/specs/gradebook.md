# Журнал

- Для кого: викладач (і лише читання для деканату за правами). Маршрут `/gradebook/$loadId`, код `features/gradebook`, API `journal/gradebook.ts`.

## Призначення

Єдине місце, де видно всю картину по дисципліні й групі: відвідуваність, оцінки, колонки оцінювання (Практична N, Модуль), підсумки й ризики; швидке введення з клавіатури та з телефона.

## Що робить зараз

- Сітка студенти × заняття + колонки оцінювання + підсумки (середнє, пропуски, ризик, пропозиція модуля). Крапки присутності, повні прізвища, прихований порожній «Прогноз» (макет A) **[зроблено]**.
- Введення з клавіатури (`interpretKey`), панель студента, мобільний `MobileJournal`.
- Майбутні заняття сховані за замовчуванням (ADR-028); перемикач виду занять як фільтр.
- Офлайн для оцінок колонок (ADR-027); створення й видалення самих колонок лише онлайн.

## Правила й інваріанти

- **Один журнал на дисципліну + групу (+ підгрупа)**; вид занять лише фільтр (ADR-024). Колонки оцінювання лише на основному навантаженні (PRACTICE→LAB→SEMINAR→CONTROL→LECTURE).
- Дата оцінки колонки = початок періоду її атестації для курсу групи (ADR-023/025).
- Єдиний записувач оцінки колонки: `writeAssessmentGrade`; LWW по клітинці.
- Шкала: 1–2 курс 12-бальна, 3–4 курс 100-бальна; блокування шкали при наявних оцінках (`assertScaleUnlocked`).
- Ризик (`LOW_GRADE`/`ABSENCES`) береться з сервера/домену, веб його не перераховує.
- Константи ширин сітки (`CELL_W`, `ASSESS_W`, `NAME_W`) міняти разом із прокруткою до клітинки; `repeat(0, …)` недійсний.

## Напрямок

Табличний інтерфейс, де основні дії (відмітка, оцінка) швидші за таблицю в Google; повний перехід від ручної таблиці **[підтверджено]**.

## Покращення (за пріоритетом)

3. Мобільний: заголовок журналу в два рядки, тулбар займає багато висоти.
4. Продуктивність: рядок перерендерюється цілком на кожну стрілку; `react-table` використовується лише як список колонок.
