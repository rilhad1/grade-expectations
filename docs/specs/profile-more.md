# Профіль, календар, експорт, «Ще»

- Для кого: усі. Маршрути `/profile`, `/more`, код `features/profile`, `features/more`, API `me`, `calendar`, `documents`.

## Призначення

Особисті налаштування, підписка на розклад у зовнішньому календарі, вигрузка своїх даних і навігація, що не вмістилась у нижнє меню (на телефоні).

## Що робить зараз

- Дані користувача, роль-перемикач, тема, вибір семестру, вихід.
- ICS-підписка за секретним токеном, «плаваючий» час (ADR-018).
- Експорт усіх даних викладача архівом: навантаження, CSV журналів, сирі JSON (оцінки заняття, колонки, відвідуваність, результати).

## Правила й інваріанти

- Вихід і зміна користувача очищують локальну БД (ADR-021); спершу `signOut()`, потім очищення.
- Токен ICS секретний, перевипуск скасовує старий.
- Експорт лише власних даних (org-scoped, `teacherId`).

## Напрямок

Один «особистий» вхід: календар, експорт, резервні копії, самообслуговування паролем.

## Покращення (за пріоритетом)

1. `useLogout`: не очищати Dexie до успішного `signOut()`.
2. ICS: одна подія на потік, фільтр видалених навантажень, гонка `getFeed`.
3. Зміна пароля самим користувачем; повторний показ тимчасового пароля не передбачено (показується один раз).
4. Експорт у XLSX у форматі, зручному для повернення в таблицю [пропозиція].
