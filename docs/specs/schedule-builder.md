# Конструктор розкладу і публікація

- Для кого: деканат (модератор). Маршрут `/admin/schedule-builder`, код `features/schedule-builder`, API `schedules`, домен `generateLessons`, `scheduleConflicts`.

## Призначення

Скласти розклад семестру зі слотів (день, пара, парність, аудиторія), побачити конфлікти й годинну норму і опублікувати його так, щоб заняття згенерувалися без втрати вже проведених.

## Що робить зараз

- Чернетка слотів, три панелі: навантаження (пошук, фільтр виду), сітка, конфлікти (від 1560 px праворуч).
- Публікація: різниця «створити / скасувати / без змін», перевірки конфліктів і годин, транзакція; незмінні версії (ADR-011).
- Потоки: слоти потоку мають збігатися, спільний викладач/аудиторія не конфлікт (ADR-029).

## Правила й інваріанти

- **Розклад і пари налаштовані вручну й працюють: публікація не має їх псувати** **[підтверджено]**. Проведені, `manuallyEdited` та з відмітками заняття регенерація не чіпає (ADR-004).
- Пари: 1=08:00, 2=09:35, 3=11:10, 4=12:50, 5=14:25, 6=16:00, 7=17:35, 8=19:00 (по 80 хв). Тиждень 31.08 = TOP.
- Заняття мають унікальний ключ `loadId+date+pairNumber`; публікація оживляє м'яко видалені, а не створює дублі.
- Навчальні дні по курсах (ADR-030).

## Напрямок

Конструктор, у якому можна швидко скласти семестр з нуля або з шаблону минулого, з відкатом дій.

## Покращення (за пріоритетом)

1. Крок майстра «Шаблон розкладу» (копіювання розкладу минулого семестру), смуга «розставлено X з Y».
2. Скасування/повтор дій (undo/redo), збереження чернетки вручну.
3. Панель «Інші групи» (щоб бачити зайнятість решти).
4. Постановка слоту потоку відразу для всіх груп (зараз для кожної окремо).
5. Публікація оновлює аудиторію вже згенерованих занять при зміні лише `roomId`; `deleteLoad` не блокується слотами історичних ревізій.
6. «Не розставлено годин» враховує курс; фільтр виду в `UnplacedPanel` не лишається після зникнення виду.

## Відкриті питання

- OQ-6: субота й кількість пар (зараз `weekday` 1..6, пар до 8).
- OQ-13: які канікули скидають парність.
