# Відкриті питання

Формат: питання → що блокує → тимчасова заглушка.

| ID   | Питання                                                                         | Блокує                            | Заглушка                                                  |
| ---- | ------------------------------------------------------------------------------- | --------------------------------- | --------------------------------------------------------- |
| OQ-1 | Як модулі (рубіжна, ДКР, середній бал, екзамен) складаються в підсумкову оцінку | Етап 5 (підсумок)                 | Підсумок не формується; модулі показуються окремо         |
| OQ-2 | Залік ставиться балом чи «зараховано / не зараховано»                           | `AttestationResult.final`, етап 5 | `final` — рядок; обидва варіанти допустимі                |
| OQ-3 | Повний перелік прав модератора; чи може він редагувати оцінки                   | `can()`, етап 2                   | Редагування оцінок і відвідуваності модератору заборонене |
| OQ-4 | Чи може викладач сам змінювати розклад, чи лише через запит                     | Етап 3–4                          | Лише через `RescheduleRequest`                            |
| OQ-5 | Шаблон відомості коледжу (шапка, підписи)                                       | Етап 5                            | Простий власний `.docx`-шаблон                            |
| OQ-6 | Шостий день (субота) і кількість пар на день                                    | Схема слотів, конструктор         | `weekday` 1..6, пар 1..5 з `BellTime`                     |

## Питання, що виникли під час аналізу концепту

| ID    | Питання                                                                                                                                              | Блокує                    | Заглушка                                                     |
| ----- | ---------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------- | ------------------------------------------------------------ |
| OQ-7  | Чим позначати заняття, «відредаговане вручну» (для безпечної регенерації)? У схемі немає відповідного поля                                           | `generateLessons`, етап 1 | Додати `Lesson.manuallyEdited Boolean` (пропозиція; ADR-004) |
| OQ-8  | Один `TeachingLoad` на один вид занять (`kind` один), а в UI навантаження показано з годинами Л/ПР/ЛР разом. Це кілька записів чи один із розбивкою? | Схема, етап 1             | Окремий запис на вид; UI групує                              |
| OQ-9  | `Grade.value Int` не передбачає «зараховано» (PASS_FAIL) і 100-бальну з дробами                                                                      | Схема                     | 1 = зараховано, 0 = ні; уточнити разом з OQ-2                |
| OQ-10 | Обов'язкова 2FA (розділ безпеки концепту) відсутня в етапах промпту                                                                                  | Етап 2                    | Відкласти, ADR                                               |
| OQ-11 | Мета MVP — II семестр 2026/2027, а сид — I семестр, оцінка робіт ≈75 днів                                                                            | План                      | Сид лишити I семестром; термін узгодити                      |
| OQ-12 | Вбудовані схеми (доменна модель, архітектура, дорожня карта) у концепті не експортувались; «4 фази, 2 перевірки» невідомі                            | Дорожня карта             | Орієнтуватися на етапи промпту                               |
